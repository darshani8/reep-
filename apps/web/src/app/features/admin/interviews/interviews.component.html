error Attempts per day cannot be lower than completed per day — the daily allowance would be unreachable, and the database refuses the row.
}

Two ceilings, and they count different things. Completed per day is the practice allowance over a rolling 24 hours, so a dropped call no longer costs a student a turn. Attempts per day counts every session, finished or not, because each one billed an upstream handshake — a cap that only counted clean finishes is a cap a reconnect loop never hits. Giving one student their attempts back is done on their own record, with a reason.

A change here applies to interviews started after it. An interview already running keeps the scopes it opened under, and a retention window already stamped on a past interview is never re-dated — a student promised 180 days keeps them.
