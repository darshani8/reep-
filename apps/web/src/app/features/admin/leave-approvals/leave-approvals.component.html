Leave policy

  • Signatures · two distinct approvers; you cannot sign twice, and you cannot decide your own request.
  • Who sees a request · a mentor sees their own group only; the Main Admin sees every request, staff leave included.
  • Refusing · this console will not send a refusal without remarks, and the applicant reads them.
info The first two lines are the rule the API enforces today, not a stored policy; the third is this screen's own — POST /leaves/…/decision accepts a refusal with no note, so a refusal made elsewhere can still arrive wordless.
