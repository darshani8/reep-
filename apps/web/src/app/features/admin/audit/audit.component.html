info An absent event means "not recorded", never "did not happen". The trail is written by the routers that call architecture_events.record_change — governance grants and access groups, feature switches, registration decisions, faculty accounts, student and batch edits, mentor assignment, SWOC entries, the question bank, the mentor notebook, account actions such as sign-out-everywhere, and every CSV download — and it stores the actor, the route, the entity and the whole before → after pair. Nothing else writes a row: a sign-in and a leave decision leave no trace here. Reading this page records nothing; downloading the export records itself. The trail is not scoped to a college — an audit row carries no college, so the Main Admin sees every event and the College filter beside these is inert.
One gap to know about while reading the Action filter: the mentor-notebook actions ({{ unfilterableActions.join(', ') }}) are stored in lower case and the endpoint upper-cases whatever this filter sends, so those rows can be listed and opened but not filtered by action.
