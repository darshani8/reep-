This harness loads the compiled module. Build it, then serve this folder over http (ES modules do not load from file://):

npx -y typescript@5 tsc apps/interview-realtime/src/VoiceVisualizer.ts \
    --target ES2022 --module ES2022 --lib ES2022,DOM --strict

npx -y http-server apps/interview-realtime/src -p 4321
# open http://localhost:4321/visualizer.html

A bare npx tsc installs a deprecated squatter package named “tsc”, not the compiler, and emits nothing. Name typescript@5 explicitly.
