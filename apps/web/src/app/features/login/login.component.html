Who can sign in

Two ways in, one roster: your college Google account, or an email & password you set yourself — only for addresses already on the roster and ending @{{ domain() }}. There is no sign-up: your account exists before you first sign in, or it does not exist at all.

  • To create or reset a password, we email a 6-digit code to that address; you enter it and choose a password. Codes last ten minutes and only the newest one counts.
  • A personal Gmail account will be refused unless that exact address is itself on the roster, and personal addresses cannot set a password here. Staff whose roster address is not @{{ domain() }} sign in with Google.
  • Not on the roster and think you should be? Ask the placement office — it cannot be fixed from this screen.

Google hands back a signed identity token — the API checks its signature, who it was issued for and that the email is verified. A password is checked against the hash you set through an emailed code. Either way the address is matched against the roster and the API hands back a signed session token held in an http-only cookie for twelve hours; every page then verifies that token and the role for itself. Setting or changing a password signs out every other device. A ?next= value is followed only when it is a path on this site.
