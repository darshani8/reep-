#
# uvicorn[standard] already pulls `websockets` in for the SERVER side of the

# asyncio API it imports does not exist on the older line.

# [crypto] is the Google sign-in change, not a version bump: the pin is
# unchanged. PyJWT signs our own HS256 session with pure Python, but verifying
# Google's ID token is RS256, and without the extra `jwt.decode(...,
# algorithms=["RS256"])` raises "Algorithm 'RS256' could not be found. Do you
# have cryptography installed?" — at CALLBACK time, in the image, on a path no
# unit test exercises without a live Google. cryptography is pinned on the next
# line as well because it reaches this environment today only as a TRANSITIVE
# dependency of google-adk/livekit-api; the day one of those drops it, ID-token
# verification would break with nothing in this file having changed.
