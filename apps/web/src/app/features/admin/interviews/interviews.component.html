Retention

what is kept, and for how long

  • Transcript · {{ retentionDays }} days by default, then deleted
  • Practice report · {{ retentionDays }} days by default, then deleted
  • Audio · the same clock · only where the student granted the audio scope
  • Erasure requests · —
shield_person {{ retentionDays }} days is the PRODUCT DEFAULT (INTERVIEW_RETENTION_DAYS). This deployment's own figure is set on the server and no endpoint reports it, so the screen names the default rather than stating a number it cannot read; that, and the per-college policy this card edits — the scopes, the cap, the time limit and the erasure queue — are the interview policy (B6.1). A downloaded recording leaves the clock behind entirely: it is a student's voice on your machine.
