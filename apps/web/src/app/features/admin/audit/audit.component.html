Reads are never recorded; not every write is.
info The trail is already being written, by seven routers and no others. A governance grant, a registration decision, a faculty account, a student or batch edit, a SWOC entry, a question-bank change and the v1 command routes each call architecture_events.record_change, which stores the actor, the route, the entity and the whole before → after pair in redesign_audit_events. Nothing else does: a sign-in, a leave decision, a mentor assignment, an import and an export leave no row today, so an absent event here means "not recorded", never "did not happen". What does not exist yet is the endpoint that reads those rows back (B2.7): until it lands the grid below stays empty and every control on this screen is disabled, because an audit log is the one screen where a sample row would be indistinguishable from something that really happened.
